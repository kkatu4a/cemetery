# Система управления кладбищем — JavaFX-клиент

Java 21, JavaFX 21, Maven Wrapper. Приложение работает с REST API проекта
`Corporate_Systems_Programming_sem5_kr_3`; прямого подключения к БД нет.

## Запуск

В отдельном терминале запустите бэкенд с ветки `feature/javafx-client-integration`:

```powershell
cd C:/Users/Sashurman/IdeaProjects/Corporate_Systems_Programming_sem5_kr_3
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21.0.11'
.\gradlew.bat bootRun
```

Затем запустите клиент с ветки `feature/http-backend-client`:

```powershell
cd C:/Users/Sashurman/IdeaProjects/cemetery
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21.0.11'
$env:BACKEND_URL = 'http://localhost:8080'
.\mvnw.cmd javafx:run
```

`BACKEND_URL` — адрес сервера, по умолчанию `http://localhost:8080`.
Задавайте переменную окружения перед запуском, в том числе в конфигурации IDE.
Файл `.env` клиент не читает; реквизиты БД ему не нужны.
Авторизация в текущем бэкенде отключена.
По умолчанию бэкенд использует H2 в памяти и теряет данные после остановки.
Для постоянного хранения настройте PostgreSQL согласно README бэкенда.

## Поведение

- Клиенты, сотрудники, участки, справочники и заявки загружаются по HTTP.
- Запросы выполняются в фоне; во время операции показан индикатор, повторные действия заблокированы.
- Ошибка сервера отображается пользователю; сохранение считается успешным только после ответа API.
- «В архив» вызывает серверный DELETE. Архивные записи скрыты в обычных списках.
  Связи существующих заявок с архивными записями продолжают отображаться.
- В форме заявки сотрудник и сведения об умершем необязательны для бронирования.
- Статус участка пересчитывает сервер в одной транзакции с изменением заявки:
  COMPLETED → OCCUPIED; другие активные заявки, кроме REJECTED → RESERVED;
  при отсутствии таких заявок → FREE. Учитываются все активные заявки участка.
- Пустой пароль при редактировании сотрудника сохраняет прежний пароль.
  Хеш не возвращается сервером и не хранится в модели интерфейса.
- Статистика считает активные записи; сумма стоимости включает все активные заявки.
  CSV/XLSX экспортирует текущий отфильтрованный список заявок.
- Восстановление и окончательное удаление доступны через API бэкенда;
  отдельного экрана архива в этой версии нет.

## Проверка

```powershell
.\mvnw.cmd verify
```

HTTP-контракты проверяются на локальном тестовом HTTP-сервере. Для интеграционных
проверок бэкенда выполните `./gradlew.bat test` в его каталоге.
